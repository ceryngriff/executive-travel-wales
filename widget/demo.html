Executive Travel Wales Chatbot Demo

This page runs the self-contained widget in demo mode with a scripted booking flow. Click the floating chat button to test the question and quote experience.

Try: How much to Heathrow?, I need an airport transfer, or just Can I get a quote? The scripted demo collects the trip details, prices it from the Merthyr Tydfil fixed-route table, and walks through to a booking confirmation.

The demo does not call a backend. When ready, use the same widget code with data-worker-url set to your Cloudflare Worker endpoint.
